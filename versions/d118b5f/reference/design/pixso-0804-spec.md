## 2×2 卡片骨架

- 基准画布：`160vp × 160vp`。
- root 内容安全区：四边 `8vp`。协议要求的 root 圆角和裁切继续遵守，但不得用额外内层 padding 把可用区域缩成旧版 136vp。
- 标题区必选；内容区可选；按钮区可选。
- 内容区与标题区至少间隔 `8vp`；内容区与按钮区至少间隔 `8vp`。
- 只使用 `0/2/4/8/12/16vp` 这组在画布中出现的间距。主结构优先 `4vp` 和 `8vp`。
- 按钮存在时，按钮贴卡片底部；无按钮时，主内容按对应分支占据剩余区域。不得使用旧版自由比例带、自由 dashboard、卡片套卡片或装饰性空白填充。

### 标题区

- 标题区由 Title 和可选右上 icon 组成。
- 信息不来自同一个应用时不显示右上 icon。
- 右上 icon：`20vp × 20vp`、圆角 `4vp`、右上放置。使用鸿蒙 SVG 规范 icon 或当前应用 icon。
- 只有主标题：`Font/Body_S/Regular`、`12fp`；建议不超过 9 个汉字。
- 有 icon 时，标题文字最大宽度 `112vp`，与 icon 间隔 `4vp`；一行显示，超出用省略号。
- 无 icon 时，标题可占满标题区；一行显示，超出用省略号。
- 主标题 + 副标题：主标题 `Font/Body_S/Bold 12fp`，副标题 `Font/Body_S/Regular 12fp`，同左边界。
- 副标题建议不超过 10 个汉字，最多两行；有 icon 时文字区最大宽度仍为 `112vp`，无 icon 时占满标题区，超出用省略号。

### 按钮区

胶囊按钮：

- 位于卡片底部，与内容区间隔 `8vp`。
- 高 `36vp`，宽度自适应；距离卡片左右边缘至少 `12vp`。
- 背景 `comp_background_tertiary`，圆角 `corner_radius_level10`。
- 文本 `Font/Subtitle_S/Medium 14fp`，单行；建议约 4 个汉字，最多 6 个。超过时逐级缩小，但不得低于 `12fp`。
- 可选 icon 为 `20vp × 20vp`，颜色与按钮文字一致；icon 与文字间隔 `8vp`，按钮内容左右 padding 各 `8vp`。

纯 icon 按钮：

- 位于卡片右下，与内容区间隔 `8vp`。
- 背景 `30vp × 30vp`，圆形，颜色 `comp_background_tertiary`。
- 中心 icon `16vp × 16vp`。

### 有按钮时的内容布局

- 单一文本区：左对齐，在内容剩余区垂直居中。
- 单一图片区：左对齐，在内容剩余区垂直居中。
- 图片 + 文本：默认图片区居左、文本区居右，中间 `8vp`；两个模块并排，整体左对齐并垂直居中。
- 当图片宽度达到高度的 2 倍以上时，改成上下布局：文本在上、图片在下，整体左对齐，间隔 `8vp`，在内容区内垂直均匀分布。
- 图片 + 两个文本区或两个文本区时，主标题/主数值所在文本区优先靠上或靠图片区，另一文本区放剩余位置；不得让按钮挤压这两个文本区。

### 无按钮时的内容布局

- 单一文本区：左对齐并贴内容区底部。
- 单一图片区：横向撑满可用宽度并贴内容区底部。
- 混排整体左对齐并在纵向均匀分布。
- 图片 + 文本：图片区置顶，文本区置底。
- 两个文本区：含大标题/主数值的文本区置顶，另一文本区置底。
- 图片 + 两个文本区：含大标题/主数值的文本区放在图片区右侧，与图片区垂直居中并置顶；另一文本区置底。
- 当图片宽度达到高度的 2 倍以上时，改成上下布局：文本在上、图片在下，整体左对齐，间隔 `4vp`，纵向均匀分布。

## 原子文字

### 常规信息文字

- 适用于新闻、摘要、日程、记录或房源等正文内容；通过字号和字重建立层级。
- 常规标题可选：默认 `Font/Body_M/Bold 14fp`，最多一行；空间不足降为 `Font/Body_S/Bold 12fp`，仍最多一行并省略。标题降为 12fp 时，正文只能用 `Font/Body_S/Regular 12fp`。
- 大字体标题可选：`Font/Title_S/Bold 20fp`，一行，超出省略。用于下一重要日程、电影票名称等核心文字。
- 正文：默认 `Font/Body_M/Regular 14fp`，最多三行；空间不足降为 `Font/Body_S/Regular 12fp`，最多四行，超出省略。
- 辅助信息可选：`Font/Caption_M/Regular 10fp`，最多一行，超出省略。
- 不同文字类型上下间隔 `4vp`。
- 纵向不足时，先压缩超过一行的正文容器，直到正文降到 12fp 且只剩一行并省略；仍不足时删除描述/辅助信息，不压缩标题、按钮或主值。

### 大数值

- 用于天气、运动健康、睡眠等核心数值。
- 单数值：默认 `Font/Display_S/Bold 38fp`，文字容器高 `40vp`、垂直居中；宽度不足时降为 `Font/Title_L/Bold 30fp`，容器高 `32vp`。
- 双数值（如睡眠时长）：两个数值都用 `Font/Title_L/Bold 30fp`，容器高 `32vp`、垂直居中。
- 单位：`Font/Caption_L/Regular 12fp`。
- 可选正文：默认 `Font/Body_M/Regular 14fp`、最多两行；降级为 `Font/Body_S/Regular 12fp`、最多两行，超出省略。
- 数字与其单位间隔 `0vp`；两个“数值 + 单位”组合之间间隔 `2vp`；数值组与辅助信息间隔 `4vp`。

## 图像与图表原子

### 单选列表视觉

目标协议禁用 `Radio`，因此用允许的 `Checkbox` 圆形样式或 Image + Text 复现同样视觉；不要输出 `Radio` 组件。

- 用于至少两个互斥选项；选项背板圆角 `12vp`，背景 `comp_background_list_card`。
- 内容左对齐，左右 padding `8vp`，上下至少 `4vp`；圆形选择控件与文字垂直居中。
- 多个背板之间间隔 `4vp`。
- 圆形控件 `16vp × 16vp`，圆角 `corner_radius_level5`；未选边框 `border_medium`，未选背景 `icon_on_fourth`，未选描边 `icon_tertiary`。
- 控件与文字/图片模块间隔 `4vp`。

### 环形图

- 用于分类较少、总和为 100% 的占比，例如设备电量、存储空间、账单占比。
- 默认 `52vp × 52vp`，最小 `44vp × 44vp`，环粗 `6vp`。
- 中心 icon `24vp × 24vp`，上下左右居中。
- 中心数字默认 `Font/Body_L/Bold 16fp`；超出环内直径时依次降为 `Font/Body_M/Bold 14fp`、`Font/Body_S/Bold 12fp`。
- 单一对象不表达百分比时可只放中心 icon；单一百分比可在环内放数值；双对象可并列两个等尺寸环。

### 线性进度条

- 用于单任务进度、下载/目标完成度，或在狭长区域比较多个项目。
- 1–2 条时，进度条粗 `8vp`，横向撑满容器，与文字模块间隔 `8vp`。
- 3 条时，进度条粗 `4vp`，横向撑满容器，与文字模块间隔 `4vp`。
- 不生成 4 条以上的密集比较；改为摘要或详情入口。

## 背景与颜色

### 通用浅色层级

- root 底色：`#FFFFFF`。
- 主文字：黑色 90%，DSL 写 `#E6000000`。
- 次文字：黑色 60%，DSL 写 `#99000000`。
- 三级文字：黑色 40%，DSL 写 `#66000000`。
- 弱线、默认环和次级背板：黑色 10%，DSL 写 `#1A000000`。
- 通用强调蓝：`#0A59F7`；10% 背景写 `#1A0A59F7`。
- 浅色渐变不是任意渐变：先铺白底，再叠“场景色 10% → 透明白 0%”的线性渐变。若一个 styles 无法同时表达底色和叠层，用 root 白底 + 全尺寸背景子组件，不改变内容结构。

## Icon 颜色

标题 icon：

- 通用背景：`#0A59F7`。
- 特殊渐变背景：跟随一级文字颜色，通常为白色。
- 原生/第三方应用：保留应用自己的色值。

内容 icon：

- 无彩色承托背景：黑色 60%，`#99000000`。
- 有彩色承托背景：白色，`#FFFFFF`。

纯 icon 按钮：

- 背景为主题色：icon 用白色。
- 背景为白色：icon 跟随该功能主色。

icon + 文字按钮：

- 主题色 10% 背景：icon 与文字同色。
- 白色背景：icon 与文字同色。

## 不得生成

- 未列入本文件的场景背景、色板、渐变或 alpha。
- 旧版 `plain-card`、`ambient-root`、`dark-focus`、`soft-material` 等自由构图/表面策略。
- `18/32/40fp` 等旧字号，或 `6/10/14vp` 等旧间距修正值。
- 56–88vp 的自由 ring、14–15% 环粗估算、4 个以上小环或多仪表盘。
- 依靠阴影、玻璃拟态、半透明卡片套卡片、装饰图形或无信息 icon 填充空白。
- 将告警、确认或品牌色仅作装饰；把通用蓝用于所有场景；改变品牌/应用 icon 原色。
