# Pixso 一致性复核

本 skill 不再提供自由构图、表面补强或场景拓展启发式。需要改善视觉时，回到 [`pixso-0804-spec.md`](pixso-0804-spec.md) 重新选择已定义的布局、文字原子、图表原子和背景分支。

## 复核顺序

1. root 是否为 2×2、`padding: 8`，且标题区、内容区、按钮区关系符合 Pixso。
2. 标题 12fp、右上 icon 20vp/圆角4、按钮 36vp 或 30vp、内容间隔 8vp 是否准确。
3. 普通文字、大数值、ring、进度条是否使用 Pixso 的固定字号和尺寸。
4. 背景是否命中一个明确分支；所有前景与按钮颜色是否来自同一分支。
5. icon 是否按标题/内容/按钮角色着色；品牌和应用 icon 是否保留原色。
6. 是否出现 Pixso 未定义的阴影、额外背板、自由渐变、装饰图形、第二主色或布局比例。

任何一项失败都通过删减信息、切换到同文件内的另一个合法分支或回退通用背景修复；不得用“更美观”“更丰富”“更现代”等理由新增视觉规则。
