# Design Compact 一致性复核

需要改善视觉时，回到 [`design-compact-aligned-spec.md`](design-compact-aligned-spec.md) 重新做任务收敛、骨架路由、信息删减和色板选择，不自由添加表面或装饰。

复核顺序：

1. 是否只有一个对象、一个主问题、一个焦点。
2. 是否明确落入一个固定骨架，且尺寸/区域/动作/背板预算成立。
3. root padding12、内部安全区、两轴预算和4vp余量是否成立。
4. 受保护文本是否通过1.2×宽度压力测试。
5. 字号、字重、按钮、icon、ring/进度、间距、圆角是否在受控范围。
6. 是否只用一个受控色族及至多一个真实状态/动作色；渐变是否两个同族 stop。
7. 素材是否承担唯一职责、数量最少、路径存在且染色正确。
8. 动态值、事件、DataModel、capability 与 CardSpec 是否闭环。

失败时依次删除 `drop`、装饰性素材、普通 `shouldKeep`、隐式入口，或切换同尺寸更简单骨架；用户明确要求的动作不删除，也不靠缩小受保护文本、裁剪或自由构图修复。
