# 颜色系统（Pixso 0804）

颜色唯一依据是 [`pixso-0804-spec.md`](pixso-0804-spec.md) 的“背景与颜色”“Icon 颜色”。本文只保留选择顺序和 DSL 编码规则；不允许创建场景拓展色。

## 选择顺序

1. 若需求精确命中专注、日程、防沉迷、耳机、低电、清理、晴天关怀、雨天打车、赛事倒计时或睡眠监督，使用对应 Pixso 分支。
2. 原生/第三方应用卡使用应用主色 10% 到透明白的叠层，应用 icon 保留原色。
3. 其他需求使用“通用背景”，即白底 + `#0A59F7` 10% 到透明白的叠层。
4. 不把相似场景映射到未列出的颜色，不创建新渐变；无法命中时回到通用背景。

## DSL 颜色写法

- DSL 只写 `#RRGGBB` 或 `#AARRGGBB`，不写 token 名。
- 黑90/60/40/10 分别写 `#E6000000`、`#99000000`、`#66000000`、`#1A000000`。
- 白100/60 分别写 `#FFFFFF`、`#99FFFFFF`。
- 颜色 10% alpha 写成 ARGB，例如蓝10 `#1A0A59F7`、橙红10 `#1AE84026`。
- 浅色场景先铺 `#FFFFFF`，再叠“场景色10% → `#00FFFFFF`”线性渐变。
- 特殊背景只允许 2-stop 全幅线性渐变：`#317AF7 → #46B1E3`、`#46484D → #467794`、`#ED6F21 → #F9A01E`、`#AC49F5 → #C386F0`。

## 前景配对

- 白底/浅色叠层：主字黑90、次字黑60、三级字黑40、弱线和默认环黑10。
- 特殊全幅渐变：主字/icon 白，次字白60；按钮白底，按钮文字/icon 使用该场景在 Pixso 指定的功能色。
- 通用标题 icon 蓝 `#0A59F7`；特殊渐变标题 icon 跟随一级文字；应用 icon 保留原色。
- 无彩色承托的内容 icon 黑60；彩色承托上的内容 icon 白。
- 主题色 10% 或白色按钮中，icon 与文字同色；纯色主题按钮 icon 白。

## 阻断项

- 任意第三个渐变 stop、径向渐变、orb、bokeh、玻璃拟态或手调透明度。
- 未列入 Pixso 映射的全幅渐变、派生浅色/暗色、多个主色族。
- 日程误用蓝色、晴天首色写成异常的 7 位 hex、睡眠卡添加赛事 icon。
- 将状态色仅作装饰，或改变品牌/应用 icon 原色。

具体数值速查见 [`color-token-values.md`](color-token-values.md)。
